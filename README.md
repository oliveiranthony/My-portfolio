# My Portfolio

Portfólio pessoal desenvolvido para apresentar meus projetos, habilidades e conhecimentos na área de desenvolvimento web.

## 🚧 Status do projeto

**Em desenvolvimento.**

Este projeto está sendo desenvolvido e aprimorado gradualmente. Novos conteúdos, funcionalidades e melhorias de design serão adicionados até a conclusão da versão final.

## 🎯 Objetivo

O objetivo deste projeto é praticar e aplicar conceitos de **HTML e CSS**, desenvolvendo uma página de portfólio moderna, organizada e responsiva.

Além de servir como prática de desenvolvimento web, o projeto também terá como finalidade apresentar meus trabalhos e conhecimentos.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript *(a ser implementado conforme a evolução do projeto)*
